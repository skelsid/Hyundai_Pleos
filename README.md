# 차량운행기록 (Vehicle Log)

업무용 차량의 **운행기록부를 자동으로 작성**하고, 출발할 때 **네 바퀴 타이어 공기압을 비교**해 알려 주는 Pleos Connect(AAOS) 앱이다.

법인 차량을 업무에 쓰면 운행기록부를 남겨야 하지만, 운전자가 매번 출발·도착 시각과 계기판 거리를 손으로 적기는 어렵다. 이 앱은 기어 변화로 운행을 감지해 시각·계기판 거리·위치·도착지를 자동으로 저장하고, 운전자는 운행이 끝났을 때 **사용자와 업무용/비업무만 고르면** 된다.

## 제출 안내

| 항목 | 내용 |
|---|---|
| 앱 이름 | 차량운행기록 (Vehicle Log) |
| 한 줄 소개 | 기어 변화로 운행을 자동 감지해 법인 차량 운행기록부를 만들고, 출발할 때 타이어·소모품·경고등을 점검해 음성으로 알려 주는 앱 |
| APK 파일 위치 | `apk/수상하면채용해주세요_차량운행기록(VehicleLog)_release.apk` (release 빌드, 서명됨, 약 28MB) |
| 에뮬레이터 버전 | Pleos Connect v2.1.0 (시스템 이미지 `android-34` / `pleos_car_emulator` / x86_64, Android Automotive, API 34) |
| 화면 규격 | 2560 x 1440 px, 160 dpi, 16:9 가로 |

### 실행 방법

1. Pleos Connect 에뮬레이터(v2.1.0)를 켠다.
2. APK 를 설치하고 앱을 연다. 에뮬레이터의 사용자 번호는 10 이다.
   ```sh
   adb install -r --user 10 apk/수상하면채용해주세요_차량운행기록\(VehicleLog\)_release.apk
   adb shell am start --user 10 -n dev.vehiclelog/.ui.MainActivity
   ```
3. 개인정보 동의 팝업에서 [동의]를 누른다.
4. 관리자 등록 화면에서 이름·사업자명·메일 주소·비밀번호(숫자 4자리, 두 번)를 넣고 [등록]을 누른다. 보내는 Gmail 계정 칸은 비워도 된다(메일 보내기만 안 된다).
5. 알림 허용을 묻는 창에서 [허용]을 누른다.
6. 메인 화면 맨 아래 [시연 모드 켜기]를 누른다. 에뮬레이터는 기어를 바꿀 수 없어, 준비된 가짜 운행을 재생해 운행 감지·출발 점검 안내·운행 종료 화면을 보여 준다.
7. 운행 종료 화면에서 도착지·사용자를 고르고 [업무용] 또는 [비업무]를 누른다. [월별 운행기록 · 분류 수정]에서 쌓인 기록을 본다.

앱을 다시 열면 관리 메뉴는 잠겨 있다. [관리자 메뉴 열기]에 4번의 비밀번호를 넣는다.

### 테스트 환경 및 필요한 설정

| 구분 | 내용 |
|---|---|
| 에뮬레이터 | Pleos Connect v2.1.0, 2560 x 1440 px, 160 dpi, RAM 4096MB |
| 앱 | `minSdk` 28, `targetSdk` 34, `compileSdk` 36 |
| 빌드 도구 | Android Studio(JDK 17 포함), Gradle 9.8.2, Android Gradle Plugin 9.4.1 |
| Pleos SDK | Vehicle 2.3.2, FusedLocation 1.1.3, TextToSpeech 3.3.1, NaviHelper 3.0.5 |

- **설치만 하면 실행된다.** API 키나 계정 설정은 필요 없다.
- **"다른 앱 위에 표시" 허용(선택):** 앱이 뒤에 있을 때도 운행 종료 화면을 바로 띄우려면 허용한다. 설정 화면이 없으면 `adb shell appops set --user 10 dev.vehiclelog SYSTEM_ALERT_WINDOW allow` 로 준다. 허용하지 않으면 알림으로 띄운다.
- **메일 보내기(선택):** 발신 전용 Gmail 계정과 앱 비밀번호 16자리를 [관리자 정보]에 넣고, 에뮬레이터가 인터넷에 연결돼 있어야 한다.
- **실차 신호:** 에뮬레이터에서는 기어·주행거리·차대번호 값이 오지 않아 시연 모드로 확인한다.

## 기능

| 기능 | 내용 |
|---|---|
| 운행 자동 감지 | 기어가 P 에서 벗어나면 시작, 다시 P 에 들어가면 종료. 앱을 열지 않아도 부팅 뒤 동작 |
| 자동 기록 | 시작·종료 시각, 계기판 거리, 출발·도착 위치와 주소, 내비 목적지, 연료(배터리) 잔량 |
| 출발 점검 | 타이어 공기압, 엔진오일·브레이크액·변속기오일, 연료(배터리), 계기판 경고등 17종을 확인해 이상이 있으면 음성으로 안내 |
| 운행 종료 화면 | 음성 안내와 함께 뜬다. 사용자를 고르고 [업무용]/[비업무] 한 번이면 끝 |
| 월별 운행기록 | 달별 운행 목록, 총 주행거리·업무용 거리·업무사용비율, 분류 수정 |
| 내보내기 | 고른 달의 운행기록표(xlsx)를 만들어 관리자 메일로 보낸다 |
| 관리자 등록·잠금 | 처음 한 번 관리자와 비밀번호(숫자 4자리)를 등록. 관리 메뉴는 비밀번호로 연다. 운전자는 운행 분류만 한다 |
| 차량 정보 | 차량번호·차대번호를 차량에서 읽어 채운다. 법인명·차종·부서는 입력 |
| 개인정보 동의 | 처음 열 때 동의를 받고, 철회하면 모든 기록을 바로 지운다 |

값을 받지 못한 항목은 추정하지 않고 비워 둔다.

## 사용하는 Pleos SDK·퍼미션

| SDK | 버전 | 쓰는 API | 용도 | 퍼미션 |
|---|---|---|---|---|
| Vehicle | 2.3.2 | `getGear` | 운행 시작·종료 감지 | `CAR_DRIVE` |
| | | `getOdometer` | 계기판 누적거리·트립 미터 | `CAR_DRIVE` |
| | | `getTire` | 타이어 공기압·저압 기준값 | `PRIVATE_CAR_SAFETY`, `CAR_SAFETY` |
| | | `getSafety` | 엔진오일·브레이크액·변속기오일 수준, 계기판 경고등 | `CAR_SAFETY` |
| | | `getFuel`, `getEvBattery` | 연료·배터리 잔량 | `CAR_ENERGY` |
| | | `getCarInfo` | 차대번호·차량 등록번호 | `CAR_INFO` |
| FusedLocation | 1.1.3 | `getLastKnownLocation` | 출발·도착 위치 | `FUSED_LOCATION` |
| NaviHelper | 3.0.5 | `getDestinationInfo`, `getCurrentLocationInfo`, 경로 이벤트 | 도착지 이름, 현재 위치 주소 | `NAVI_ROUTE` |
| TextToSpeech | 3.3.1 | `speak` (기기 내 엔진) | 출발 점검·운행 종료 음성 안내 | `TTS_SERVICE` |

조회용 퍼미션만 쓰고, 차량 제어(`CONTROL_*`) 퍼미션은 쓰지 않는다.

## 알려진 한계

- 에뮬레이터는 기어·주행거리·소모품·차대번호 값을 주지 않아 시연 모드(가짜 운행 재생)로 확인했다. 실차 값은 확인하지 못했다.
- 타이어 10%, 연료 15%, 짧은 움직임 100m·3분 기준은 가정값이다.
- 메일 발송은 가짜 SMTP 서버로만 시험했다.
- 화면은 16:9(2560 x 1440) 에뮬레이터에서만 보았다.
